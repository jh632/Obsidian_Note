```c
void ServiceDog(void)
{
    EALLOW;
    SysCtrlRegs.WDKEY = 0x0055;   // 先写入 0x55
    SysCtrlRegs.WDKEY = 0x00AA;   // 紧接着写入 0xAA，完成一次"喂狗"

}
```

### 3. 已知 DSP 的晶振为 30MHz，系统配置程序和 ADC 配置程序如下，请问系统时钟、高速时钟、内核时钟、ADC 模块的转换时钟分别是多少 Hz？并写出计算过程。

```c
SysCtrlRegs.PLLCR.bit.DIV = 0x0A;
SysCtrlRegs.HISPCP.all = 0x0001;
SysCtrlRegs.PCLKCR.bit.ADCENCLK = 1;
AdcRegs.ADCTRL3.bit.ADCCLKPS = 3;
AdcRegs.ADCTRL1.bit.CPS = 0;
```

**计算过程：**

```
SYSCLKOUT = (30MHz / 2) × 10 = 150MHz          （PLLCR.DIV = 0x0A，即 10 倍频）
HSPCLK    = SYSCLKOUT / 2 = 75MHz              （HISPCP = 0x0001，即 2 分频）
FCLK      = HSPCLK / (2×3) = 12.5MHz           （ADCCLKPS = 3，即 2×3 分频）
ADCCLK    = FCLK / (1+CPS) = 12.5MHz           （CPS = 0）
```

即：系统时钟（SYSCLKOUT）150MHz，高速时钟（HSPCLK）75MHz，内核时钟（FCLK）12.5MHz，ADC 模块的转换时钟（ADCCLK）12.5MHz。
