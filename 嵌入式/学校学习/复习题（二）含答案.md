## 一、填空题

1. F28335 有（**32**）位浮点运算单元，主频可高达（**150MHz**）。
2. F28335 片上存储器包括：（**256K×16**）位 Flash，（**34K×16**）位 SRAM，（**8K×16**）位 Boot ROM，（**2K×16**）位 OPT ROM。
3. CPU 内核指令周期为（**6.67ns**），内核电压为（**1.8V**），I/O 引脚电压为（**3.3V**）。
4. 物理上将程序空间和数据空间统一成一个（**4M×16**）位的空间。F28335 为（**哈佛结构**）的 DSP，在逻辑上有（**4M×16**）位的程序空间和（**4M×16**）位的数据空间。
5. F28335 的时钟源有两种：采用外部振荡器作为时钟源（简称外部时钟），采用内部振荡器作为时钟源（简称内部时钟），在（**X1**）与（**X2**）之间连接一个晶体，就可以产生时钟源。
6. WD 复位关键字寄存器 WDKEY，向 WDKEY 写入 0x55 后紧接着写入（**0xAA**）则清除 WDCNTR 寄存器。
7. 看门狗模块的作用是（**防止程序发生死循环**）。
8. 造成看门狗计数器复位的原因有（**WDCHK 寄存器写入的数值不是"101"**），（**没有按时给看门狗计数器"喂狗"**），（**WDKEY 寄存器写入的数值非"0x55"或"0xAA"**）。
9. TMS320F28335 的三种低功耗模式：（**IDLE（闲置）**）、（**STANDBY（待机）**）、（**HALT（暂停）**）。
10. CPU 定时器 0，1，2 是完全一样的（**32**）位定时器，这些定时器带有可预先设定的周期和（**16**）位时钟预分频。
11. 构成 DSP 软件工程的要素有（**cmd 文件**）、（**库文件**）、（**主函数**）。
12. TI 公司的 DSP 处理器的软件开发环境是（**CCS**），使用链接器文件（填后缀名）（**.cmd**）后，将编译器生成的目标文件（填后缀名）（**.obj**）链接成（填后缀名）（**.out**）后，通过仿真器接口（**JTAG**）后烧录至 DSP 中。
13. 在链接器命令文件中，PAGE1 通常指（**数据**）存储空间，PAGE0 通常指（**程序**）存储空间。
14. 直接寻址中从页指针的位置可以偏移寻址（**128**）个单元。
15. 解决 MMR 写操作的流水线冲突时，一般可采用（**推荐指令**）和（**插入空操作指令**）的方法。
16. F28335 共有（**88**）个 GPIO，分成了（**3**）组。其中 A 组管理（**32**）个，每个 GPIO 最多支持（**4**）个功能，若将其配置为普通 IO 功能时，对方向寄存器而言，写（**1**）表示该 IO 口为输出。
17. F28335 内部有（**16**）个中断线，其中包括（**2**）个不可屏蔽中断（RESET 和 NMI）与（**14**）个可屏蔽中断。PIE 总计可管理（**96**）个中断资源，将其分为（**12**）组，每组（**8**）个。
18. F28335 有（**7**）个外部引脚中断，但 88 个 GPIO 引脚只有（**64**）个可通过软件配置成外部中断引脚，其中（**GPIO0~GPIO31**）只能配置为外部中断 1 和 2，（**GPIO32~GPIO63**）只能配置为外部中断 3、4、5、6 和 7。
19. F28335 的中断采用（**CPU 级**）、（**外设级**）、（**PIE 级**）三级管理机制。中断优先级最高的是（**复位**）中断，NMI 是（**硬件不可屏蔽**）中断，NMI 中断优先级是（**2**）。

## 三、补全程序

### 1. 根据注释补全 PIE 级中断使能程序

```c
PieCtrlRegs.PIEIFR2.bit.INTx3 = 1;      // 使能 PIE2 组中的第 3 个 IFR 标志位
PieCtrlRegs.PIEIER1.bit.INTx1 = 1;      // 使能 PIE1 组的第 1 个中断
PieCtrlRegs.PIEACK.all = 0x0002;        // 响应 PIE2 组中断
PieCtrlRegs.PIECTRL.bit.ENPIE = 1;      // 使能 PIE 级中断
IER |= 0x0004;                          // 使能 CPU 的 INT3 中断
```

{

    GpioCtrlRegs.GPAMUX1.bit.GPIO1 = 0;   // GPIO1 复用为 GPIO 功能
