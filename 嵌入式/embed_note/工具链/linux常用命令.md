# Linux 常用命令

## ls — 列出目录内容

### 基础用法

```bash
ls              # 列出当前目录文件
ls /path/to/dir # 列出指定目录文件
```

### 常用选项

| 选项             | 作用                         | 示例                |
| -------------- | -------------------------- | ----------------- |
| `-l`           | 长格式（权限、大小、时间等）             | `ls -l`           |
| `-a`           | 显示隐藏文件（`.`开头）              | `ls -a`           |
| `-la`          | 组合：长格式 + 隐藏文件              | `ls -la`          |
| `-h`           | 文件大小 human-readable（K/M/G） | `ls -lh`          |
| `-R`           | 递归列出子目录内容                  | `ls -R`           |
| `-t`           | 按修改时间排序（最新的在前）             | `ls -lt`          |
| `-S`           | 按文件大小排序（最大的在前）             | `ls -lS`          |
| `-r`           | 反转排序方向                     | `ls -lr`          |
| `-d`           | 只列出目录本身，不列内容               | `ls -d */`        |
| `-1`           | 每行只输出一个文件名                 | `ls -1`           |
| `-i`           | 显示 inode 编号                | `ls -li`          |
| `--color=auto` | 彩色输出（目录/文件/链接着色）           | `ls --color=auto` |

### 组合示例

```bash
ls -lha          # 长格式 + 隐藏文件 + 人类可读大小
ls -lt           # 按修改时间排序
ls -ltr          # 按修改时间排序，最旧的在前（查看最新日志时常用）
ls -lS           # 按大小降序排列
ls -lhR /etc     # 递归查看 /etc 下所有文件，带可读大小
```
