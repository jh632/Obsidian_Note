# 悬空 GPIO 引脚与贯通电流

## 概述

MCU 休眠时电流居高不下（mA 级而非 μA 级）的常见元凶之一：**悬空（Floating）GPIO 引脚**引发的贯通电流（Shoot-through Current）。未使用的 GPIO 若配置为浮空输入且无外部连接，其 CMOS 输入结构中的 PMOS 和 NMOS 会因引脚电位漂移在中间电平而同时导通，在 VDD 和 GND 之间形成直流通路。

> 低功耗不是靠"省"出来的，而是靠精准的"控制"算出来的。

## 基本原理

### CMOS 反相器结构

一个数字输入引脚内部最前端是 PMOS + NMOS 串联的互补结构：

- 输入高电平 → PMOS 截止，NMOS 导通 → **无直流通路**
- 输入低电平 → PMOS 导通，NMOS 截止 → **无直流通路**
- 浮空中间电平 → **PMOS 和 NMOS 同时半开** → VDD 到 GND 直接导通 → 贯通电流

### 悬空引脚为什么会产生中间电平

浮空输入引脚无外部连接时，相当于一根暴露在空气中的微型天线：

- 空间电磁辐射
- 板载高频信号串扰
- 人体接触

都会使引脚电位漂移在 VDD/2 附近，而非稳定的 0 或 1。

### 动态功耗叠加

如果电位在施密特触发器（Schmitt Trigger）翻转临界点附近反复横跳，不仅产生贯通电流，还会导致内部数字逻辑频繁状态切换，带来额外的动态功耗。

## 实战解决方案（按优先级排列）

### 黄金法则：模拟输入模式（Analog Mode）

配置为模拟模式后，芯片内部会**物理上断开施密特触发器与引脚的连接**，从源头上消除数字输入通道。

```c
void LowPower_FixFloatingGPIO(void)
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};

  // 1. 开启所有 GPIO 端口的时钟
  __HAL_RCC_GPIOA_CLK_ENABLE();
  __HAL_RCC_GPIOB_CLK_ENABLE();
  __HAL_RCC_GPIOC_CLK_ENABLE();
  __HAL_RCC_GPIOD_CLK_ENABLE();

  // 2. 配置为模拟输入，无上下拉
  GPIO_InitStruct.Mode = GPIO_MODE_ANALOG;
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  GPIO_InitStruct.Pin = GPIO_PIN_ALL;

  // 3. 对未使用的端口批量处理
  HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);
  HAL_GPIO_Init(GPIOD, &GPIO_InitStruct);

  // 4. 部分使用的端口用位操作筛选
  GPIO_InitStruct.Pin = (GPIO_PIN_ALL & ~GPIO_PIN_0);
  HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

  // 5. 关闭 GPIO 时钟进一步省电
  __HAL_RCC_GPIOC_CLK_DISABLE();
  __HAL_RCC_GPIOD_CLK_DISABLE();
}
```

寄存器层面即设置 `GPIOx_MODER` 为 `11`（Analog Mode）。

### 白银法则：内部强制上下拉

适用于不能配置为模拟模式的情况（如外部中断引脚），通过内部上拉/下拉电阻施加固定电位。

> **注意：** 如果引脚外部已有下拉电阻，内部配置了上拉后，休眠时会形成分压回路，产生持续的静态泄露电流。

## 隐藏的"刺客引脚"

### 1. 调试接口引脚（SWD / JTAG）

`PA13(SWDIO)` 和 `PA14(SWCLK)` 复位后默认有内部上拉/下拉。脱离调试器独立供电时若未处理，容易产生几百微安漏电。

**正确做法：** Release 版本代码中关闭调试接口，将其当作普通引脚配置为模拟输入。

### 2. 已断电的外设接口

用 MOS 管切断传感器电源后，如果 MCU 的 SPI/I2C 引脚仍保持高电平，电流会通过传感器芯片内部的 **ESD 保护二极管**倒灌回传感器供电网络。这种现象叫**寄生供电（Parasitic Powering）**。

## 排查思路

1. 用万用表逐个点引脚，找到影响功耗的关键引脚
2. 重点检查：浮空输入引脚、SWD 引脚、已断电外设的连接引脚
3. 休眠前统一执行 `LowPower_FixFloatingGPIO()` 类函数
