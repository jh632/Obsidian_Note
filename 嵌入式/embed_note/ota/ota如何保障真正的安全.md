# 1 ota过程中的问题

## 1.1 下载过程断网

```
Firmware

100MB

下载到

62MB

WiFi断开
```

解决方案:断电续传

## 1.2 写flash时断电
```
OTA Partition

████████████████

写到一半

↓

突然掉电
```
里面既不是旧程序
也不是新程序
如果 Bootloader 不知道这一点：
设备就变砖了

解决方案:Bootloader 必须能够识别"升级未完成"状态。

## 1.3 新程序启动失败
```
新版本：

v2.0
```
有一个bug
启动后进入hardfault

解决方案:ota需要支持自动回滚

# 2 OTA真正要解决的问题

| 问题        | 对应机制                 |
| --------- | -------------------- |
| 网络中断      | 断点续传、HTTP Range      |
| 数据损坏      | SHA-256、数字签名         |
| Flash 写失败 | 校验、重试、事务化写入          |
| 断电        | A/B 分区、Boot Metadata |
| 新版本崩溃     | Trial Boot、Rollback  |
| 用户数据      | 独立数据分区               |
| 大规模发布     | 灰度发布                 |
| 非法固件      | 签名验证                 |
| 版本回退      | Anti-Rollback        |
