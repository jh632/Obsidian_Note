# 1 如果直接覆盖当前分区
程序：

```
APP

100KB
```

CPU：

正在执行：

```
0x18000
```

与此同时：

OTA：

```
Erase

0x18000
```

CPU 下一条指令：

```
?????
```

程序立即崩溃。
当你擦除了正在执行的 Flash：
CPU 连下一条指令都读不到。
因此：
**绝大多数 MCU 都不能覆盖当前运行的程序。**
# A/B分区方案

```
Flash

+----------------+
| Bootloader     |
+----------------+
| APP A          |
+----------------+
| APP B          |
+----------------+
```

**Boot Metadata 永远最后修改。**
