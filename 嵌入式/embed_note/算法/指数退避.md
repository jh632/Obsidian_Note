# 指数退避

## 概述

指数退避是一种**重试间隔递增算法**：每次失败后，等待时间翻倍（`base × 2^n`），从而分散请求压力，避免"雷鸣群效应"压垮对端或总线。

常见场景：断线重连、I2C/SPI 总线重试、传感器忙等待、网络拥塞控制。

## 核心公式

嵌入式禁止使用 `pow()` 浮点函数，一律用**左移运算**计算 2^n：

```
实际延时 = MIN( base_ms << retry_cnt, max_delay_ms )
```

```
retry 0:  100 ms       (base << 0)
retry 1:  200 ms       (base << 1)
retry 2:  400 ms       (base << 2)
retry 3:  800 ms       (base << 3)
  ...       ↓ 截断于 max_delay_ms
retry N:  max_delay_ms
```

## 关键参数

| 参数 | 推荐值 | 说明 |
|:---|:---|:---|
| `base_ms` | 100 ~ 500 ms | 第一次重试等待基数，大于总线/网络 RTT |
| `max_retries` | 5 ~ 10 次 | 超过后停止增长，判定永久失败 |
| `max_delay_ms` | 30 ~ 60 s | 防止位移溢出（`uint32_t` 左移超 31 位回绕） |

## 非阻塞实现（状态机）

禁止 `delay_ms()` 阻塞，必须配合系统 Tick 计时。适用于 RTOS / 裸机。

```c
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    uint32_t base_ms;       // 基础时间 (ms)
    uint32_t max_delay_ms;  // 最大上限 (ms)
    uint8_t  retry_cnt;     // 当前重试计数 (从0开始)
    uint32_t tick_start;    // 等待开始的绝对时间戳 (ms)
    uint32_t cur_delay;     // 本次实际等待时间 (用于超时判断)
    uint8_t  state;         // 0=空闲, 1=等待中
} backoff_t;

void backoff_init(backoff_t *b, uint32_t base, uint32_t max) {
    b->base_ms = base;
    b->max_delay_ms = max;
    b->retry_cnt = 0;
    b->cur_delay = 0;
    b->state = 0;
}

// 计算退避时间并启动非阻塞等待
uint32_t backoff_start(backoff_t *b) {
    uint32_t delay;
    if (b->retry_cnt >= 31) {
        delay = b->max_delay_ms;
    } else {
        delay = b->base_ms << b->retry_cnt;
        if (delay > b->max_delay_ms) delay = b->max_delay_ms;
    }

    // 随机抖动：打散多机重连时刻，防撞车
    // ponytail: 用 rand() 简单打散；无 rand() 时可用 XORShift 或位移近似
    if (delay > 1) {
        delay = (rand() % delay) + 1;
    }

    b->cur_delay = delay;
    b->tick_start = get_sys_tick_ms();  // 替换为你的系统时钟函数
    b->state = 1;
    return delay;
}

// 轮询调用：放在主循环或定时器中
uint8_t backoff_is_timeout(backoff_t *b) {
    if (b->state == 0) return 0;
    if (get_sys_tick_ms() - b->tick_start >= b->cur_delay) {
        return 1;
    }
    return 0;
}

void backoff_reset(backoff_t *b) {
    b->retry_cnt = 0;
    b->cur_delay = 0;
    b->state = 0;
}

void backoff_fail(backoff_t *b) {
    if (b->retry_cnt < 255) b->retry_cnt++;
}
```

> 上面的 `backoff_is_timeout` 使用 `cur_delay` 判断超时，比直接用 `max_delay_ms` 更严谨——每次重试的实际延时不同。

## 避坑要点

1. **防溢出**：`uint32_t` 最大 2^32 − 1。`base_ms=1000` 时，第 22 次左移（`1000<<22 ≈ 4.19e9`）即溢出。**`retry_cnt` 上限务必控制在 10 以内**，或在代码中做溢出钳位。
2. **时钟回绕**：32 位毫秒计时器约 49 天回绕。用 `current - start >= wait` 做减法判断（无符号减法天然处理回绕），**绝对不要用** `current > start + wait`。
3. **无 `rand()` 的替代**：XORShift 算法，或简单位移近似 `delay = (delay >> 1) + (delay >> 2)`，避免多设备完全同步重连。
