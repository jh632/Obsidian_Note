# 双缓冲数据结构

## 定义

双缓冲（Double Buffering）是一种通过使用两个缓冲区来提高数据传输效率的技术。当一个缓冲区正在被使用（如读取或显示）时，另一个缓冲区可以同时进行数据填充（如写入或采集），从而实现并行处理，减少等待时间。

## 核心思想

**空间换时间**：通过增加一个缓冲区，避免数据处理时的阻塞，提高系统吞吐量。

## 解决问题

- 1.避免读写冲突（最核心）
- 2.避免等待（流水线）
- 3.保证数据完整性

## 工作原理

```
┌─────────────────────────────────────────────────────────┐
│                    双缓冲工作流程                        │
├─────────────────────────────────────────────────────────┤
│  时刻1:  Buffer A [读取/显示]  Buffer B [写入/采集]      │
│  时刻2:  Buffer A [写入/采集]  Buffer B [读取/显示]      │
│  时刻3:  Buffer A [读取/显示]  Buffer B [写入/采集]      │
│  ...                                                    │
└─────────────────────────────────────────────────────────┘
```

### 工作步骤

1. **初始化**：分配两个缓冲区 A 和 B
2. **填充阶段**：向缓冲区 A 写入数据，同时缓冲区 B 可读取
3. **切换阶段**：当缓冲区 A 填满后，切换角色
4. **重复**：缓冲区 B 填充时，缓冲区 A 可读取

## 数据结构设计

### 方式一：指针交换（最常用）

```c
typedef struct {
    uint8_t *buf[2];      // 两个缓冲区指针
    uint8_t write_idx;    // 写缓冲区索引 (0 或 1)
    uint16_t size;        // 每个缓冲区大小
    volatile uint8_t ready; // 写缓冲区是否就绪
} double_buf_t;

// 读取当前可读缓冲区
uint8_t* dbuf_get_read_buf(double_buf_t *dbuf) {
    return dbuf->buf[1 - dbuf->write_idx];
}

// 获取写缓冲区
uint8_t* dbuf_get_write_buf(double_buf_t *dbuf) {
    return dbuf->buf[dbuf->write_idx];
}

// 写完成后切换缓冲区
void dbuf_switch(double_buf_t *dbuf) {
    dbuf->write_idx = 1 - dbuf->write_idx;
    dbuf->ready = 1;
}
```

### 方式二：使用状态标志

```c
typedef struct {
    uint8_t *buf[2];
    uint8_t state;        // 0: buf0写, buf1读; 1: buf0读, buf1写
    uint16_t write_pos;   // 写位置
    uint16_t read_pos;    // 读位置
    uint16_t size;
} double_buf_t;
```

## 嵌入式应用场景

### 1. LCD 显示刷新

```c
// 显示双缓冲
#define LCD_WIDTH  320
#define LCD_HEIGHT 240
#define BUF_SIZE   (LCD_WIDTH * LCD_HEIGHT * 2) // RGB565

static uint8_t frame_buf[2][BUF_SIZE];
static uint8_t front_buf = 0;  // 前台缓冲区（正在显示）
static uint8_t back_buf = 1;   // 后台缓冲区（正在绘制）

// 绘制到后台缓冲区
void draw_to_backbuffer(void) {
    uint16_t *buf = (uint16_t *)frame_buf[back_buf];
    // 绘制图形...
}

// 切换缓冲区
void swap_buffers(void) {
    front_buf = back_buf;
    back_buf = 1 - back_buf;
    // 启动DMA传输到LCD
    LCD_DMA_Transfer(frame_buf[front_buf], BUF_SIZE);
}
```

### 2. ADC 数据采集

```c
#define ADC_BUF_SIZE 256

static int16_t adc_buf[2][ADC_BUF_SIZE];
static volatile uint8_t adc_buf_idx = 0;
static volatile uint8_t adc_ready = 0;

// DMA回调函数
void ADC_DMA_Complete(void) {
    adc_ready = 1;  // 标记缓冲区就绪
}

// 处理ADC数据
void process_adc_data(void) {
    if (adc_ready) {
        int16_t *read_buf = adc_buf[adc_buf_idx];
        adc_buf_idx = 1 - adc_buf_idx;  // 切换缓冲区
        adc_ready = 0;

        // 处理数据...
        for (int i = 0; i < ADC_BUF_SIZE; i++) {
            // 数据处理
        }
    }
}
```

### 3. 音频播放

```c
#define AUDIO_BUF_SIZE 1024

static int16_t audio_buf[2][AUDIO_BUF_SIZE];
static volatile uint8_t audio_buf_idx = 0;

// I2S DMA回调
void I2S_DMA_HalfComplete(void) {
    // 前半部分播放完成，填充前半部分
    fill_audio_data(&audio_buf[audio_buf_idx][0], AUDIO_BUF_SIZE / 2);
}

void I2S_DMA_Complete(void) {
    // 后半部分播放完成，填充后半部分
    fill_audio_data(&audio_buf[audio_buf_idx][AUDIO_BUF_SIZE / 2], AUDIO_BUF_SIZE / 2);
    audio_buf_idx = 1 - audio_buf_idx;  // 切换缓冲区
}
```

### 4. 串口通信接收

```c
#define UART_BUF_SIZE 256

static uint8_t uart_buf[2][UART_BUF_SIZE];
static volatile uint8_t uart_rx_idx = 0;
static volatile uint16_t uart_rx_cnt = 0;

// 接收完成回调
void UART_RxComplete_Callback(void) {
    uart_rx_idx = 1 - uart_rx_idx;  // 切换缓冲区
    uart_rx_cnt = 0;  // 重置计数
}

// 接收数据
void UART_Rx_Callback(uint8_t data) {
    uart_buf[uart_rx_idx][uart_rx_cnt++] = data;
}
```

## 优缺点

### 优点

| 优点 | 说明 |
|------|------|
| **提高效率** | 读写并行，减少等待时间 |
| **避免撕裂** | 读取时不会读到一半新的数据 |
| **平滑输出** | 显示、音频等应用更流畅 |
| **降低CPU负载** | 可配合DMA使用，CPU只需处理逻辑 |

### 缺点

| 缺点 | 说明 |
|------|------|
| **内存占用** | 需要两倍缓冲区空间 |
| **同步复杂** | 需要正确处理缓冲区切换 |
| **延迟增加** | 可能引入一帧延迟 |

## 注意事项

### 1. 切换时机

```c
// 错误：在填充过程中切换
// 正确：确保填充完成后再切换
void safe_switch(double_buf_t *dbuf) {
    // 等待写操作完成
    while (dbuf->writing) {}
    dbuf->write_idx = 1 - dbuf->write_idx;
}
```

### 2. 中断安全

```c
// 在中断中切换缓冲区时，需要禁用中断
void dbuf_switch_irq(double_buf_t *dbuf) {
    __disable_irq();
    dbuf->write_idx = 1 - dbuf->write_idx;
    __enable_irq();
}
```

### 3. 内存对齐

```c
// 确保缓冲区对齐，便于DMA传输
__attribute__((aligned(4)))
static uint8_t buf[2][BUF_SIZE];
```

## 与环形缓冲的区别

| 特性 | 双缓冲 | 环形缓冲 |
|------|--------|----------|
| **切换方式** | 整体切换 | 逐字节/块 |
| **适用场景** | 帧数据、块数据 | 流数据 |
| **实时性** | 需等待填满 | 可随时读取 |
| **内存占用** | 2倍 | 1倍+N |
| **复杂度** | 简单 | 中等 |

## 典型应用场景总结

1. **显示系统**：LCD/LED屏刷新，避免闪烁
2. **音频系统**：I2S/PCM音频播放
3. **数据采集**：ADC连续采样
4. **通信系统**：UART/SPI数据接收
5. **图像处理**：摄像头帧缓冲

## 扩展：三缓冲

在某些高性能场景（如GPU渲染）中，可以使用三缓冲进一步提高效率：

```c
typedef struct {
    uint8_t *buf[3];
    uint8_t read_idx;    // 读索引
    uint8_t write_idx;   // 写索引
    uint8_t display_idx; // 显示索引
} triple_buf_t;
```

三缓冲允许：读、写、显示同时进行，但内存开销更大。
