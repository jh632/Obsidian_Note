# Linux 常用命令

> 按使用场景组织的 Linux 常用命令速查，嵌入式开发 + WSL 日常使用。
> 大纲先行，后续学习中逐条补充命令示例。

## 文件与目录

- [x] `ls` — 列出目录内容（`-l` `-a` `-h` `-t` `-S` 组合） ✅ 2026-08-12
- [x] `cd` / `pwd` — 切换 / 查看当前目录 ✅ 2026-08-12
- [x] `mkdir` / `touch` — 创建目录 / 文件 ✅ 2026-08-12
- [ ] `cp` / `mv` / `rm` — 复制 / 移动 / 删除
- [ ] `find` — 按名称、类型、大小查找文件
- [ ] `ln` — 软链接 / 硬链接
- [ ] `du` / `df` — 目录大小 / 磁盘空间
- [ ] `file` / `tree` — 文件类型 / 目录树

## 文本处理

- [ ] `cat` / `less` / `head` / `tail` — 查看文件（`tail -f` 看日志）
- [ ] `grep` — 文本搜索（`-r` `-n` `-i` `-v`）
- [ ] `sed` — 流式替换
- [ ] `wc` / `sort` / `uniq` — 统计 / 排序 / 去重
- [ ] `diff` — 文件对比
- [ ] `awk` / `cut` — 字段提取（了解）

## 进程与系统

- [ ] `ps` / `top` — 查看进程与资源
- [ ] `kill` — 终止进程
- [ ] `free` — 内存占用
- [ ] `uname` / `lscpu` — 系统与 CPU 信息
- [ ] `crontab` — 定时任务

- [ ] `ping` / `ip` / `ifconfig` — 网络连通与接口信息
- [ ] `curl` / `wget` — HTTP 请求 / 下载
- [ ] `ssh` / `scp` — 远程登录 / 传输文件
- [ ] `netstat` / `ss` — 端口与连接
- [ ] `tcpdump` — 抓包（了解）

- [ ] `chmod` — 修改权限
