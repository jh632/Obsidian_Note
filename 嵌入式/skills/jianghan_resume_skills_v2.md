# 技术技能

## 核心技术栈

**嵌入式系统开发**
- MCU 开发：ESP32, STM32（ARM Cortex-M），掌握启动流程、内存布局、低功耗设计
- RTOS：FreeRTOS 任务调度、临界区保护、同步机制（互斥锁、信号量、Task Notify）
- 传感器集成：Goodix GH3220 SDK 集成，PPG 信号处理，佩戴检测方案设计

**编程语言与工具**
- C 语言（精通）：嵌入式底层开发，寄存器级操作，驱动开发
- Rust（熟练）：嵌入式系统开发，所有权系统、借用检查、模式匹配
- CMake：交叉编译环境搭建，工具链配置，项目构建管理

**硬件调试与通信**
- 调试工具：J-Link, ST-Link, OpenOCD，寄存器级调试
- 通信协议：SPI, I2C, UART, CAN, BLE，通信优化与问题定位
- 信号处理：PPG 信号质量分析，传感器数据融合

## 项目技能

**GH3220 心率血氧传感器驱动开发**
- 完成 V4300 SDK 迁移，优化寄存器配置，解决兼容性问题
- 实现硬件 ADT + 软件 ADT 佩戴检测方案
- G-sensor 数据接入，实现运动检测与多传感器事件管理

**ESP32 低功耗项目开发**
- 实现 SD 卡存储方案，优化文件系统性能
- 开发马达驱动控制，实现精确的振动反馈
- 电源管理策略优化，降低系统功耗

**FreeRTOS 系统优化**
- 优化任务调度策略，提升系统响应速度
- 选择合适的通信机制，平衡性能与资源占用
- 分析系统资源占用，优化内存使用效率

## 技术特点

- 深入理解硬件底层原理，追求系统级优化
- 问题驱动学习，快速掌握新技术并应用于项目
- 文档化思维，注重知识积累与经验分享
