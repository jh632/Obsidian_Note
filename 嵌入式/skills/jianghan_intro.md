# 蒋瀚 - 嵌入式系统工程师

## 🎯 核心专长

### 1. **嵌入式系统开发**
- MCU 架构深度理解（ARM Cortex-M, ESP32, STM32）
- 启动流程分析（上电复位 → startup → SystemInit → main）
- 内存布局优化（.text, .data, .bss, heap, stack）
- 存储器体系架构（SRAM, DRAM, Flash, EEPROM, FRAM）

### 2. **实时操作系统 (RTOS)**
- **FreeRTOS 专家级理解**：
  - 临界区实现（关中断 + 嵌套计数）
  - 互斥锁 vs 信号量（所有权概念、优先级继承）
  - Task Notify 轻量化机制（直接使用 TCB 成员变量）
  - suspendall 与临界区的区别
- 任务调度与同步机制
- 低功耗设计与电源管理

### 3. **传感器集成与算法**
- **Goodix GH3220 SDK 深度集成**：
  - PPG 信号处理（HR/SpO2/NADT/ADT）
  - 佩戴检测配置（硬件 ADT vs 软件 ADT）
  - G-sensor 运动检测（MPU6050 数据接入）
  - 多传感器事件管理器配置
- 寄存器级调试与配置优化
- 算法参数调优与性能分析

### 4. **Rust 嵌入式开发**
- 从 C 开发者视角掌握 Rust 核心概念：
  - 所有权系统与借用检查
  - 生命周期管理
  - 模式匹配与错误处理（Option/Result）
  - 零成本抽象在嵌入式的应用
- Rust 嵌入式开发框架（no_std, embedded-hal）
- C 与 Rust 混合开发

### 5. **构建系统与工具链**
- **CMake 精通**：
  - 工具链文件配置（arm-none-eabi-gcc）
  - Cortex-M 项目模板
  - 交叉编译环境搭建
  - 后处理命令（hex/bin 生成）
- 交叉编译与调试工具使用

### 6. **硬件调试与问题定位**
- 寄存器配置分析（位域操作、内存对齐）
- 通信协议调试（SPI, I2C, UART）
- 信号质量分析与优化
- 内存泄漏与溢出检测
