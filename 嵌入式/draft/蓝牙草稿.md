## 下午修改分析：活体检测（NADT）开启方式

你修改了 3 个文件，核心变化是把 **NADT（非接触式活体检测，soft ADT green）** 集成到了佩戴检测流程中。

---

### 1. `gh3220.c` — 佩戴采样时同步启动 NADT

**改前**：佩戴检测到后，只启动 HR + SPO2：
```c
Gh3x2xDemoStartSampling(GH3X2X_FUNCTION_HR | GH3X2X_FUNCTION_SPO2);
```

**改后**：同时启动 NADT（soft ADT green）：
```c
Gh3x2xDemoStartSampling(GH3X2X_FUNCTION_HR | GH3X2X_FUNCTION_SPO2 | GH3X2X_FUNCTION_SOFT_ADT_GREEN);
```

脱离佩戴停止采样时同理，同时也停止了 NADT。

---

### 2. `gh_demo_hook.c` — WearEventHook 重构，按 NADT 结果分流

原来的代码用了 Goodix 的多传感器事件框架（`GhMultSensorWearEventManagerIsEnable`、`GhMultSensorWearEventSend` 等），现在全部替换成 NADT 的逻辑：

| 事件类型                           | 旧行为                     | 新行为                                            |
| ------------------------------ | ----------------------- | ---------------------------------------------- |
| **Non-Living wear-off**（非活物脱离） | 停止 HR/SOFT_ADT，启动多传感器重检 | **只设 status=false，不停止采样** → 留给 NADT 在信号变化时重新评估 |
| **Air wear-off**（空气/无物体脱离）     | 通过多传感器框架发事件             | **设 status=false + 停止 HR/SPO2/NADT 采样**        |
| **Living wear-on**（活体佩戴）       | 发多传感器事件                 | **设 status=true，确认活体**                         |
| **Object wear-on**（物体佩戴）       | 启动 HR/SOFT_ADT          | **只打日志，不做动作**                                  |

关键设计：NADT 的 non-living 事件**不停止采样**，保持 GH3220 在采集状态，等下次信号变化（如从桌面挪到手腕）时 NADT 重新判断为 living。

---

### 3. `gh_demo_config.h` — 其他配置

除了 clang-format 自动格式化外，有一个有实际意义的改动：

```c
#define __DRIVER_OPEN_ALL_SOURCE__ (1)  →  (0)
```

切换到非全部源码模式（支持 Goodix 算法库）。

---

### 总结

**NADT 活体检测的开启方式**：不再走旧的多传感器 wear event 框架，而是：
1. 佩戴检测到活体 → **在 2 秒启动延迟中同步开启 NADT green LED 通道**
2. NADT 的检测结果（living / non-living / air）直接通过 `s_sensor_value.wear_status` 和 `gh3220_wear_off_stop_sampling()` 控制采样状态
3. **Non-living 不贸然停采样**，给 NADT 留重新评估的机会
