# GH3220 Driver — 完整配置清单

## 一、文件架构总览

```
driver_gh3220/
├── driver_user/                     ← 用户自己写的驱动层
│   ├── gh3220.h                    ← GPIO引脚、SPI配置、API声明
│   └── gh3220.c                    ← init/ISR/process task/wear handling
├── demo_kernel_code/               ← Goodix SDK 内核层
│   ├── kernel/
│   │   ├── gh_demo_config.h        ← ★ 驱动功能宏配置 (主配置文件)

│   │   ├── gh_demo_reg_array.c     ← ★ 驱动寄存器配置表 (8个list)
│   │   ├── gh_demo.c / .h          ← SDK Demo API (init/start/stop/interrupt)
│   │   ├── gh_demo_hook.c / .h     ← hook函数实现
│   │   ├── gh_demo_protocol.c      ← 协议解析 (Goodix 调试协议)
│   │   └── gh_demo_inner.h         ← 内部头文件
│   └── driver/                     ← 芯片底层驱动
│       ├── inc/ (gh_drv.h, gh_drv_config.h, ...)
│       └── src/ (gh_drv_config.c, gh_drv_control.c, ...)
├── demo_algo_code/                 ← Goodix 算法层
│   ├── goodix_algo_application/
│   │   ├── inc/
│   │   │   ├── gh3x2x_demo_algo_config.h     ← ★ 算法功能宏配置

│   │   │   └── ...
│   │   └── src/
│   │       ├── gh3x2x_demo_algo_hook.c        ← ★ 算法结果回调 (HR/SPO2/ADT等)
│   │       ├── gh3x2x_demo_algo_reg_array.c   ← ★ 算法寄存器配置表
```

## 二、硬件接口配置 (`gh3220.h`)

| 配置项         | 值                                 | 说明                     |
| -------------- | ---------------------------------- | ------------------------ |
| SPI 频率       | `1 MHz`                            | GH3220_SPI_MAX_FREQ      |
| SPI 总线/引脚  | MOSI=GPIO1, MISO=GPIO3, SCLK=GPIO2 | SPI2_HOST                |
| CS 引脚        | `GPIO_NUM_8`                       | 硬件 CS                  |
| RESET 引脚     | `GPIO_NUM_16`                      |                          |
| INT 引脚       | `GPIO_NUM_10`                      | 中断输入, 上升沿触发     |
| FIFO Watermark | `60`                               | 每60个sample触发一次中断 |
