## wifi_ws 组件完整流程图

### 1. 连接状态机

```mermaid
stateDiagram-v2
    [*] --> DISCONNECTED: wifi_ws_init()
    DISCONNECTED --> CONNECTING: WIFI_EVENT_STA_START→ esp_wifi_connect()
    CONNECTING --> CONNECTED: IP_EVENT_STA_GOT_IP→ wifi_ws_client_start()
    CONNECTED --> WS_CONNECTING: WS client start
    WS_CONNECTING --> WS_CONNECTED: WEBSOCKET_EVENT_CONNECTED
    WS_CONNECTED --> REGISTERING: 发送 register 请求
    REGISTERING --> REGISTERED: 收到 register_resp (code=0/1)→ 提取 session_id→ 启动 ping 定时器(30s)
    REGISTERED --> COLLECTING: 收到 start_collect 命令→ ws_data_push_start(mask)
    COLLECTING --> REGISTERED: 收到 stop_collect 命令→ ws_data_push_stop()
    
    DISCONNECTED --> DISCONNECTED: WIFI_EVENT_STA_DISCONNECTED→ 指数退避重连
    CONNECTED --> DISCONNECTED: WS disconnected→ stop ping timer
    REGISTERING --> WS_CONNECTED: register 被拒绝(code≠0)
    
    note right of COLLECTING
        周期性数据推送:
        ws_fast_push_task (200ms)
        ws_env_push_task (1000ms)
    end note
    
    note right of REGISTERED
        心跳维持:
        ping_timer 每30s发送 ping
    end note
```

### 核心流程总结

| 阶段              | 入口                          | 状态迁移                                     | 关键操作                                              |
| --------------- | --------------------------- | ---------------------------------------- | ------------------------------------------------- |
| **WiFi连接**      | `wifi_ws_init()`            | DISCONNECTED → CONNECTING → CONNECTED    | 加载NVS→WiFi init→connect→获取IP                      |
| **WebSocket连接** | `wifi_ws_client_start()`    | CONNECTED → WS_CONNECTING → WS_CONNECTED | 构建URI→WS client start→连接服务器                       |
| **注册**          | `WEBSOCKET_EVENT_CONNECTED` | WS_CONNECTED → REGISTERING → REGISTERED  | 编码register→发送→解析register_resp→存session_id→启ping   |
| **心跳**          | `ping_timer` 每30s           | REGISTERED/COLLECTING                    | 编码ping→发送→解析ping_resp                             |
| **命令**          | 来自服务器的 `type=command`       | 状态不变                                     | 解析→ws_app_handler分发→回复cmd_resp                    |
| **数据采集**        | `start_collect`             | REGISTERED → COLLECTING                  | 按mask创建推送任务→200ms/1000ms周期→swap_and_get→JSON→send |
| **OTA升级**       | `start_ota`                 | COLLECTING → REGISTERED                  | 停止采集→独立任务→HTTPS下载→烧录→通知→重启                        |
| **关机**          | `shutdown`                  | 任何非COLLECTING状态                          | 应答→3s延迟→AXP2101关电源                                |
