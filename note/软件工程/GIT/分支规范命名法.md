
| 前缀 | 用途 |
| --- | --- |
| `feature/` | 新功能 |
| `bugfix/` | 普通缺陷修复 |
| `hotfix/` | 线上紧急修复 |
| `release/` | 发布分支，如 `release/1.4.0` |
| `chore/` | 构建、依赖、配置等杂项 |
| `docs/` | 文档 |
| `refactor/` | 重构，不改行为 |
| `test/` | 测试相关 |
| `spike/` | 技术预研/实验分支 |
## 团队规范
```
feature/<JIRA-ID>-<kebab-description>
bugfix/<JIRA-ID>-<kebab-description>
hotfix/<JIRA-ID>-<kebab-description>
release/<version>

docs/<kebab-description>

```
