提交信息（commit message） Conventional Commits，和分支前缀能对应上，团队统一即可。

格式

```text
<type>(<scope>): <subject>

<body>

<footer>
```


```text
feat(auth): add OAuth login
fix(order): handle null total
hotfix(payment): fix callback timeout
docs(api): update auth guide
refactor(payment): extract callback handler
test(order): add cart total cases
chore(deps): upgrade eslint
```

中文团队也可以：

```text
feat(auth): 新增 OAuth 登录
fix(order): 修复订单金额为空
```

关键是全团队一致，不要中英混着来。

| type     | 用途         |
| -------- | ---------- |
| feat     | 新功能        |
| fix      | 缺陷修复       |
| hotfix   | 线上紧急修复     |
| docs     | 文档         |
| style    | 格式调整，不影响逻辑 |
| refactor | 重构，不改行为    |
| perf     | 性能优化       |
| test     | 测试         |
| build    | 构建/依赖      |
| ci       | CI 配置      |
| chore    | 杂项         |
| revert   | 回滚         |
