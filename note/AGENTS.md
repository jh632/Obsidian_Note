# 笔记规范

## 照片

- 笔记引用的照片文件统一存放在笔记库目录的 `image/` 目录。
- 使用 Obsidian wikilink 引用照片，例如 `![[image/照片名称.png]]`。
- 你在整理笔记时应该追求图文并茂

## 标签

- 每篇笔记的 YAML frontmatter `tags` 必须包含笔记所在目录及其全部上级目录名称。
- 各级目录名称分别写入标签，并保留已有的主题标签。
- 例如，`嵌入式/嵌入式/算法/滤波实现/高斯滤波.md` 的 `tags` 至少包含 `嵌入式`、`算法` 和 `滤波实现`,最顶层的嵌入式不属于笔记无需理会

## 格式

- 你的笔记应该具有可读性 图大于表,表大于文字
-  当你帮我梳理创建笔记时笔记风格请阅读 [[STYLE]] @STYLE.md
