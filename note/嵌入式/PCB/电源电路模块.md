# 电源电路模块

围绕 **10 个供电电路实例**，学习 USB 输入保护、LDO、多路降压、电池管理、音频、电机、隔离电源与 LED 恒流。每例配有官方原理图、供电路径和关键元件说明。资料整理于 2026-11-09；PDF 页码从文件第一页开始计数。

## 基础知识

### 1. Type-C：引脚作用与原理图绘制要点

Type-C 定义连接器的形状、引脚和正反插连接方式。设计时分别确定三个条件：
- **使用 USB 2.0 还是 USB 3.x 数据
- 接口负责供电还是受电
- 是否需要 USB PD 协商**。


#### 1.1 通用引脚：电源、连接检测与辅助信号

完整的 Type-C 母座有 A、B 两排共 24 个触点，另有金属外壳焊脚。用于 USB 2.0 或仅供电的连接器，可以省略部分触点；画图前应核对具体型号的脚位表。

| 引脚 | 标准母座脚位 | 作用 | 绘制原理图时的要点 |
| --- | --- | --- | --- |
| **VBUS** | A4、A9、B4、B9 | 电源正极，默认供电电压为 5V；通过 PD 协商可支持其他电压 | 接通全部 VBUS 引脚，标清接口电源与板内电源节点，并画出保护、滤波和电源转换路径 |
| **GND** | A1、A12、B1、B12 | 电源电流的返回路径和信号参考地 | 全部连接电路地，确保供电与信号具有完整回流路径 |
| **CC1** | A5 | 连接检测、正反插方向识别、供电角色及电流能力检测；USB PD 使用有效的 CC 通道通信 | 根据接口角色连接 Rp、Rd 或 Type-C 控制器 |
| **CC2** | B5 | 与 CC1 配合完成正反插检测 | 与 CC1 分开连接，分别处理上拉、下拉或控制器连接 |
| **SBU1、SBU2** | A8、B8 | 部分替代模式、附件模式使用的辅助通道 | 普通 USB 2.0、USB 3.x 数据连接通常留空；使用对应模式时再连接专用电路 |
| **Shield / 外壳焊脚** | 编号随型号变化 | 机械固定、屏蔽和静电泄放 | 根据产品的机壳地、电路地及 EMC 设计确定连接方式 |

VBUS 上的电流来自供电端，经板内负载后从 GND 返回。CC 上的电流用于状态检测，负载供电走 VBUS。

#### 1.2 CC1、CC2：为什么需要电阻

供电端称为 **Source**，受电端称为 **Sink**：

| 接口角色 | CC 上的基本连接 | 含义 |
| --- | --- | --- |
| **Source：供电端** | CC1、CC2 分别提供上拉 Rp，部分控制器使用等效电流源 | 宣告供电端的存在，以及能够提供的电流能力 |
| **Sink：受电端** | CC1、CC2 分别经一个标称 **5.1kΩ 的下拉 Rd** 接 GND | 宣告受电端的存在 |
| **DRP：双角色电源端口** | 控制器交替呈现 Rp、Rd，并管理角色 | 使端口能够根据连接情况担任供电端或受电端 |

以固定受电端为例，其基本连接为：

```text
CC1（A5）── Rd1 5.1kΩ ── GND
CC2（B5）── Rd2 5.1kΩ ── GND
```

连接后，供电端的 Rp 和受电端的 Rd 形成可检测的电压。符合规范的 Type-C Source 检测到有效的受电端连接后，开启 VBUS 的 5V 供电。受电端可以检测 CC 电压，判断供电端宣告的电流能力。

正反插会改变母座上哪一个 CC 引脚接通线缆中的 CC 通道，因此 **CC1、CC2 各自接一个 Rd，并保持独立**。电阻值参与连接状态识别，不能任意取值。若控制器已经集成 Rd，外部连接按控制器要求处理。

Rd 本身不设定整板取电电流。受电电路应根据供电端宣告能力、USB 工作状态和适用规则确定取电上限；通过 PD 取得其他电压、电流组合时，由 PD 控制器协商，并由电源电路执行。

#### 1.3 USB 2.0：D+、D− 的作用与连接

USB 2.0 使用一组差分数据线，称为 D+、D−。两根线共同传输数据，USB 2.0 High-Speed 的最高速率为 480Mbps。

| 信号 | 标准母座脚位 | 连接方法 |
| --- | --- | --- |
| **D+ / DP** | A6、B6 | 两个 D+ 在母座附近并接，连接 USB 芯片的 D+ |
| **D− / DN** | A7、B7 | 两个 D− 在母座附近并接，连接 USB 芯片的 D− |

D+、D− 各安排两个触点，是为了支持正反插。并接后，板内仍然是一组 USB 2.0 数据线。

```text
Type-C 母座                              USB 芯片

A6（D+）──┐
          ├── ESD 保护区域 ── 串联电阻 ── D+
B6（D+）──┘

A7（D−）──┐
          ├── ESD 保护区域 ── 串联电阻 ── D−
B7（D−）──┘
```

ESD 器件用于处理接口引入的静电瞬态，串联电阻用于调整信号边沿和减轻反射。串联电阻是否需要、阻值多大，应按 USB 芯片的硬件设计要求确定。

USB 设备端的连接识别还涉及数据线上拉。Full-Speed 设备使用 D+ 上拉，许多 USB 芯片已集成该功能；画图时核对芯片是否要求外接上拉，以及是否需要检测 VBUS。

只用于受电的接口可以将 D+/D− 留空，CC 仍按受电端要求连接。

#### 1.4 USB 3.x：SuperSpeed 的 TX、RX 差分对

USB 3.0 引入 **SuperSpeed**，最初速率为 5Gbps。USB 3.x 使用额外的发送、接收差分对；同一个 Type-C 接口还可以保留 D+/D−，用于 USB 2.0 兼容连接。

| 信号 | 标准母座脚位（按 +、− 顺序） | 作用 |
| --- | --- | --- |
| **TX1+、TX1−** | A2、A3 | 第 1 组 SuperSpeed 发送差分对 |
| **RX1+、RX1−** | B11、B10 | 第 1 组 SuperSpeed 接收差分对 |
| **TX2+、TX2−** | B2、B3 | 第 2 组 SuperSpeed 发送差分对 |
| **RX2+、RX2−** | A11、A10 | 第 2 组 SuperSpeed 接收差分对 |

**TX 表示发送，RX 表示接收；“+、−”表示一组差分信号的两个端点。**画图时还要核对 USB 芯片对 TX、RX 的命名视角。

在常见的单通道 USB 3.x 设计中，芯片提供一组 TX 和一组 RX。Type-C 插头正反插会改变它们对应的母座触点，需要根据 CC 检测到的方向，通过高速切换开关 **MUX** 选择正确路径。部分芯片已经集成切换功能。

```text
CC1、CC2 ── Type-C 控制器 ── 方向控制 ──┐
                                       ↓
TX1±、TX2± ─────────────────────── 高速 MUX ── 芯片 TX±
RX1±、RX2± ─────────────────────── 高速 MUX ── 芯片 RX±
```

TX1/TX2、RX1/RX2 通过切换或相应的多通道电路处理，不能照搬 USB 2.0 同名触点直接并接的方式。支持双通道的 USB 3.x 设计会使用两组通道，连接方式由控制器架构决定。

绘图时还需确认发送端的 AC 耦合电容位置、芯片内部是否已集成电容，以及高速 MUX、ESD 器件的带宽和寄生电容是否满足目标速率。

### 2 TVS二极管
**TVS 二极管**(Transient Voltage Suppressor Diode,瞬态电压抑制二极管)是专门用来吸收瞬间高压脉冲的保护器件,常用于 ESD、浪涌、电快速瞬变(EFT)等防护。

**内部结构**

本质上是一个专门设计过的硅 PN 结,工作在反向击穿(雪崩)区。普通二极管反向击穿会损坏,而 TVS 的结面积大、掺杂特殊,可以反复承受大电流击穿而不损坏,击穿后电压几乎不再升高,这就是"钳位"的原理。

**类型**

- **单向 TVS**:一个方向像普通二极管导通,另一个方向击穿钳位。用于直流电源线、单极性信号线。
- **双向 TVS**:两个方向都能击穿钳位,用于正负电压摆动的信号线,比如 RS-485、音频线。
- **低电容 TVS 阵列**:把多路 TVS 加上导向二极管集成在一个封装里,结电容可低到 1pF 以下,用于 USB、HDMI、以太网等高速接口。
- **大功率 TVS**:封装较大(如 SMBJ、SMCJ 系列),额定功率几百瓦到几千瓦,用于电源端的浪涌防护。

**主要特点**

- 响应极快,ns 级甚至更快,比压敏电阻、气体放电管快得多
- 钳位电压低而稳定,保护精度高
- 可重复使用,正常工作时漏电流很小
- 缺点是能承受的能量有限,不适合单独扛雷击这类超大能量

**选型思路**

1. 先看被保护线路的最高工作电压,选 V_RWM 略高于它(例如 5V 的 USB 电源线常选 V_RWM=5V 的型号)
2. 确认钳位电压 V_C 低于被保护芯片的耐压
3. 根据防护目标选功率或峰值电流:ESD 看是否通过 IEC 61000-4-2,浪涌看 IEC 61000-4-5 对应的 I_PP
4. 高速信号线重点看结电容,电源线可以不太在意
5. 最后按封装和空间选型号

**布局要点**

- 紧靠接口放置,先过 TVS 再进入后级电路
- 走线短、直,接地过孔靠近 TVS 的地脚,减小寄生电感
- 信号线最好直接从 TVS 焊盘"穿过"走线,而不是用一小段分支连过去

**常见应用**

USB、HDMI、以太网口,按键和触摸接口,电源输入端,通信总线(CAN、RS-485),以及各种 GPIO 引出的外部接口。

## example01 · 立创天空星(TYPEC ESD/TVS静电保护 LDO)

**供电路径：USB 5V → F1 → +5V → SCJA1117B 的 3.3V 版本 → +3V3。**

先看 USB 输入和保护部分：

![[image/电源电路-example01-天空星-USB输入.png]]

- 1️⃣ F1：输入电源过流保护
	- 正常情况下，电阻很小，允许电流通过。
	- 电流过大时，器件发热。
	- 温度升高后，内部电阻急剧增加。
	- 限制故障电流，保护后级电路。
	- 故障解除并冷却后，电阻恢复到较低水平。
- 2️⃣ D2：ESD 静电保护:它主要保护 USB 的 D+、D- 两根数据线。
	 ![[Pasted image 20261109112120.png]]
	-  USB 接口属于外部接口，用户可以直接触摸。
	- 静电可能直接进入 MCU 的引脚，导致：
		- GPIO 损坏。
		- USB PHY 损坏。
		- 芯片内部绝缘结构击穿。
		- 设备出现不稳定或永久损坏。
	- 把它理解成：正常情况下相当于不存在，异常高压出现时迅速提供一条泄放通道
	- PCB 设计重点：
		- TVS 必须尽可能靠近 USB 接口放置，接地路径尽可能短、宽。
		- 否则静电电流经过较长的 PCB 走线，会产生额外的寄生电感和电压尖峰，降低保护效果。
- 3️⃣ R9、R12：22Ω 串联电阻
	- 这两个电阻分别串联在 USB D- 和 D+ 数据线上
	- 阻抗匹配（主要原因）:
		- USB 2.0 规范要求全速/低速驱动器的输出阻抗在 28~44 Ω 之间
		- 外面串一个 22 Ω 左右的电阻（常见 22 Ω、27 Ω、33 Ω），总阻抗就落进规范范围(根据芯片手册调整)
- 4️⃣R13：1.5kΩ 上拉电阻
	- 这是专门针对 STM32F1 USB FS 的设计。
	- `这个上拉电阻是用来告诉 USB 主机，已经连接了一个全速设备。STM32F1 系列是没有内置这个上拉电阻的。而 STM32F4 系列在芯片内部集成了可软件控制的上拉电阻，我们可以通过配置 USB 控制寄存器来启用或者禁用。对于 STM32F4 和大部分国产元件中这个电阻默认是不贴的。`

![[image/电源电路-example01-天空星-LDO.png]]
- 1️⃣C19 和 C20：输入输出电容
	- C19：输入滤波电容
		- 稳定输入电源
		- 为输入电源降噪
来源：[立创官方《天空星原理图》](https://wiki.lckfb.com/zh-hans/tkx/hardware/schematic.html)，
## example02 · 立创天巧星 MSPM0G3519(LDO)

**供电路径：+5V → ME6211C33M5G-N → F1 → 3V3。** 取自 `Schematic_V1.0.3` 第 1 页左上角。

![[image/电源电路-example02-天巧星-LDO.png]]

关注 LDO 的 CE 连接，以及输出侧标称 500mA 的 F1 和 D2。它们的位置都在稳压器之后。

- 1️⃣C1：输入端大容量电容
	- **大容量电容：提供较多电荷储备**。
	- 降低输入电源上的低频和部分高频噪声。
- 2️⃣ C2：100nF 高频去耦电容
	- 它和 C1 的作用有重叠，但侧重点不同。
	- 100nF 电容：**处理高频电源噪声**。
- 3️⃣ LDO1：ME6211C33M5G-N
	- 第一：CE 引脚。CE 是 Chip Enable，也就是芯片使能。
- 4️⃣ C3：输出端大容量电容
	- 假设 MCU 原本消耗 50mA，突然开启 Wi-Fi，电流需求瞬间增加到 300mA。
	- 这时候 LDO 内部控制环路需要一定的响应时间。
	- 在这段时间内，C3 可以提供一部分瞬态电流，减轻 3.3V 电压下跌。
- 5️⃣C4：输出端高频去耦电容
- 6️⃣ F1：500mA 保险丝
- 7️⃣ D2：SMBJ3.3A，TVS 瞬态电压抑制二极管
	- TVS二极管普通状态下基本不导通
	- 正常工作：不影响 3.3V 供电。
	- 瞬态过压：快速导通，吸收瞬态能量。
	- 瞬态结束：恢复到正常截止状态。
来源：[立创官方《天巧星硬件设计》](https://wiki.lckfb.com/zh-hans/tqx-mspm0g3519/hardware-design.html)，章节“天巧星 MSPM0G3519 原理图 V1.0.3”。

## example03 · 多路数字供电：立创庐山派 K230

**供电路径：8～24V → TPS54302DDCR → 5V → 四路 TLV62569DBVR → 0.8V / 1.1V / 3.3V / 1.8V。** 适合学习处理器核心、存储器和外设需要不同电压时，怎样组织电源树。

第一级把外部宽范围输入转换为 5V：

![[image/电源电路-example05-庐山派-宽压输入.png|668]]

- **U6、L1、C10/C11**：构成 Buck 降压的主要功率路径。SW 是快速切换的节点，电感之后才是供给负载的直流输出。
- **R10、R11 → FB**：把输出电压分压送回芯片，控制器据此调整开关动作、维持输出电压。C9 跨接 BOOT 与 SW，为内部高侧开关驱动提供电荷。

第二级从公共 5V 母线生成四路电压：

![[image/电源电路-example05-庐山派-四路降压.png]]

- **相同芯片，不同输出**：比较各路 FB 分压电阻。图中公式为 $V_{out}=0.6\times(1+R_{上}/R_{下})$；例如 0.8V 一路使用 33.2kΩ / 100kΩ，计算约为 0.799V。
- **EN 与上电顺序**：0.8V 一路直接上拉 EN，其他几路增加了电容，利用 RC 充电延迟使能。设计时要把各电源轨的启动波形与处理器要求对照。

## example04 · 单节锂电池与 USB 输出：ESP32-S3-USB-OTG

**供电路径：USB 5V → ME4054B-N → 电池；电池 → AP2007SPER → 5V USB 输出。** 板内还通过 SY8089AAAC 生成 3.3V。这里重点看充电、升压和供电切换之间的配合。

![[image/电源电路-电池-充电与升压.png]]

- **左侧充电**：U3 的 BAT 接电池，PROG 通过 R9 设定充电电流。图中 R9 为 4.7kΩ，按图中公式得到约 213mA。
- **右侧升压**：电池通过 L2 和 U2 生成 `VBUS_DEV`，R7/R10 将输出反馈到 FB；`BOOST_EN` 控制是否开启升压。电池端输入电流可按 $I_{bat}\approx5V\times I_{USB}/(\eta V_{bat})$ 估算，η 为升压转换效率，低电量时要留意输入电流增加。

USB 输出可以来自外部 USB，也可以来自电池升压：

![[image/电源电路-电池-供电选择与限流.png]]

- **左侧 Q1/Q2/Q3**：由 `DEV_VBUS_EN` 控制外部 USB 向 `VBUS_DEV` 供电。图中明确给出切换顺序：先关闭当前来源，再开启目标来源。
- **右侧 U4 MIC2005A**：对 USB 输出实施标称 500mA 限流，并提供故障信号。它位于两种供电来源汇合之后。

## example05 · Codec 与 ADC 供电：ESP32-S3-Korvo-2

**供电路径：VCC_5V → RT9043GB → Codec_3V3 → ADC_VCC33。** 数字部分由另一颗 ETA3409S2F 降压供电；这里关注音频采集与编解码电路的独立供电支路。

![[image/电源电路-example09-Korvo2-音频LDO.png]]

- **U12 RT9043GB**：音频支路使用独立 LDO。R126/R128 设置约 3.3V 输出，R418 将该电源继续送往 ADC。
- **C85 与 C81/C82**：分别位于 LDO 输入、输出侧。除了稳压器旁的电容，Codec、ADC 电源脚附近也有各自的去耦电容，沿同名网络可以继续追到负载。
- **C80**：跨接在输出与反馈节点之间，用于反馈支路；它的位置与输出对地的 C81/C82 不同，按芯片推荐电路配置。
- **回流与发热**：沿 `ADC_GND` 追踪音频回流路径。以 5V 降为 3.3V、负载 100mA 为例，LDO 的主要损耗约为 $(5-3.3)\times0.1=0.17W$。电源噪声还要结合 LDO 在相关频率下的 PSRR（电源纹波抑制能力）与 PCB 布局判断。

来源：[Espressif 官方原理图，V3.1.2，PDF 第 4 页 `04_AUDIO`](https://dl.espressif.com/dl/schematics/SCH_ESP32-S3-Korvo-2_V3.1.2_20240116.pdf#page=4)，数字供电见同一 PDF 第 2 页。

## example06 · 扬声器功放供电：TPA3116D2EVM

**供电路径：4.5～26V 直流电源 → PVCC → Class-D 功放内部开关桥 → LC 输出滤波 → 扬声器。** 功放将电源能量转换为扬声器功率，供电能力要跟着输出功率变化。

![[image/电源电路-音频功放-TPA3116D2.png]]

- **C7、C18：各 220µF / 35V**。为两组 PVCC 供电脚提供本地储能，减轻音频功率突变时的电压下跌。
- **C8/C19：100nF；C9/C20：1nF**。这些电容承担高频旁路，布局时靠近对应的 PVCC 引脚，缩短开关电流回路。
- **L1～L4 与 C21～C24**：位于功放输出侧，将开关波形中的高频分量滤除。它们和 PVCC 对地的去耦电容承担不同任务。
- **BTL（桥接负载）输出**：每只扬声器连接同一声道的 `+`、`−` 输出，两端均由功放驱动，均不能直接接 GND。

供电电流可先按功率估算：

$$
I_{in,avg}\approx\frac{P_{out,L}+P_{out,R}}{\eta V_{in}}
$$

例如两声道各输出 20W、输入 24V，**假设效率为 90%**，平均输入电流约为 1.85A；再按输出峰值、压降和温升确定电源余量。

来源：[TI《TPA3116D2EVM Evaluation Module》，SLOU336B，PDF 第 5 页 Figure 2](https://www.ti.com/lit/ug/slou336b/slou336b.pdf#page=5)；输入范围与接线见 PDF 第 2～4 页。

## example07 · 有刷直流电机供电：DRV8876

**供电路径：4.5～37V 直流电源 → VM → 芯片内部 H 桥 → OUT1 / OUT2 → 电机。** H 桥由四个功率开关组成，可以控制绕组电流的方向与通断。

![[image/电源电路-有刷电机-DRV8876.png]]

- **VM 对地的 0.1µF 与 CBulk**：前者承担芯片附近的高频旁路，后者为启动、堵转等电流变化提供本地储能。CBulk 的容量与供电线长度、电源响应和制动方式有关。
- **VCP—VM 的 0.1µF、CPH—CPL 的 0.022µF**：用于内部电荷泵，为高侧 MOSFET 提供驱动电压。阅读时确认这两组电容各自跨接的引脚。
- **VREF、IPROPI**：VREF 与 IPROPI 上的电阻共同参与设置限流阈值；IPROPI 也能接 MCU ADC，用来监测电机电流。

电机绕组储存了能量，开关切换后仍会有电流。低侧慢衰减时，电流在绕组与低侧开关形成的回路中续流；高阻衰减时，电流可经体二极管回到 VM，抬高母线电压。因此，除启动电流外，还要检查减速时的 VM 波形、电容耐压和电源吸收能量的能力。

来源：[TI《DRV8876》数据手册，PDF 第 19 页 Figure 18](https://www.ti.com/lit/ds/symlink/drv8876.pdf#page=19)。续流路径见第 10 页 Figure 10，本地储能与供电线寄生电感见第 31 页 Figure 40。

## example08 · 三相电机母线供电：DRV8316xEVM

**供电路径：4.5～35V 输入 → 防反接电路 → π 型滤波 → VM → 三相驱动器 → 电机。** BLDC 是无刷直流电机，驱动器通过三个半桥依次控制三相绕组。

先看输入、储能和滤波：

![[image/电源电路-三相电机-输入保护与滤波.png]]

- **Q2 与 Q1/D5**：构成输入防反接电路。Q2 位于大电流供电路径上，选型与布局要考虑导通损耗和散热。
- **L3：1µH，前后各有电容组**：构成 π 型滤波，用于减轻母线上的传导干扰。
- **C16：330µF**：位于滤波后的 VM 侧，为母线提供储能；C17～C24 的小容量电容分布在滤波两侧。

- **C3 与 C6**：分别连接 VM—VCP、CPH—CPL，为内部电荷泵服务；OUTA/B/C 则把功率送往三相绕组。

## example09 · 低压隔离供电：SN6505xEVM

**供电路径：标称 5V → SN6505A/B 推挽驱动 → 变压器 T1 → D1/D2 整流 → Vout → TPS76701 LDO → Vldo 5V。** 适合学习隔离通信、浮地测量电路怎样获得独立的电源与地参考。

![[image/电源电路-隔离-SN6505.png]]

- **U1 与 T1**：U1 两个开关端交替导通，将直流电源转换为变压器能传递的交变激励；T1 使用中心抽头绕组。能量经磁耦合传到副边。
- **D1/D2 与电容组**：副边整流、滤波后得到 `Vout`；再由 U2 生成稳压输出 `Vldo`。输入、整流后、LDO 输出侧各有 0.1µF、1µF、10µF 电容。
- **1:1.1 匝比**：副边电压要给整流器压降和 LDO 压差留下余量；输出能力还受变压器、驱动器和散热限制。
- **GND1 / GND2**：分别属于原边、副边。跨边界的数据连接也应采用信号隔离，保持电源与信号共同构成的隔离边界完整。

手册注明该 EVM 的 PCB 在两侧地之间仅提供 **50V 隔离**。本例按低压隔离电路阅读；实际产品的隔离等级要结合变压器、PCB 间距及接口一起确定。

来源：[TI《SN6505A and SN6505B Evaluation Module》，SLLU233，PDF 第 5 页 Figure 2](https://www.ti.com/lit/ug/sllu233/sllu233.pdf#page=5)，板级隔离条件见第 3 页。

## example10 · LED 恒流升压：TPS61165EVM-283

**供电路径：5V → L1 / TPS61165 升压级 → D1 → 三颗串联白色 LED → R2 → GND。** 这块评估板以 4.5～5.5V 输入进行设计与测试，LED 电流约 357mA，输出电压随 LED 串的正向压降变化。

![[image/电源电路-LED恒流-TPS61165.png]]

- **L1：10µH；D1：MBR0540T1**：SW 开关导通时电感储能，关断时电感经 D1 向输出送能，形成升压电路。
- **R2：0.56Ω → FB**：芯片调节的是 LED 电流。满亮度时 FB 基准为 200mV，因此 $I_{LED}\approx0.2/0.56\approx357mA$。
- **CTRL**：接收调光控制，支持 PWM 与 EasyScale；亮度由控制信号调整。
- **JP2 与开路保护**：LED 串断开时，输出会继续上升并触发过压保护。输出电容、整流二极管等器件的耐压要覆盖开路条件。

图中输入接口标有 `5V–18V Max`，本例三颗 LED 的使用条件以手册正文的 **4.5～5.5V** 为准；当输入高于 LED 串压降时，这种升压结构无法保持恒流调节。

来源：[TI《TPS61165EVM-283》，SLVU224D，PDF 第 10 页“4.1 Schematic”](https://www.ti.com/lit/ug/slvu224d/slvu224d.pdf#page=10)，设计与测试条件见该手册；200mV 基准见 [TPS61165 数据手册](https://www.ti.com/lit/ds/symlink/tps61165.pdf)。
